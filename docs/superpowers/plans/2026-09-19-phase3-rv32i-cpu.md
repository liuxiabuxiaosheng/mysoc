# Multi-Cycle RV32I CPU Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement and verify a modular, non-pipelined RV32I CPU connected to the existing phase-two CPU memory bus.

**Architecture:** A finite-state core shares one request/response memory interface for instruction fetches and data accesses. Decoder, immediate generator, ALU, and register file are independently testable modules; the core coordinates them through FETCH, DECODE, EXECUTE, MEMORY, WRITEBACK, and FAULT states.

**Tech Stack:** SystemVerilog 2012, Icarus Verilog 13.0, VVP, PowerShell.

## Global Constraints

- PC reset value is `0x0000_0000`.
- Register x0 always reads zero and ignores writes.
- Memory requests remain stable until `ready` or `error`.
- Misaligned halfword/word accesses and illegal instructions halt with a fault code.
- Existing phase-one and phase-two tests remain passing.
- No multiply/divide, CSR, interrupt, cache, pipeline, DMA, or firmware toolchain in this phase.
