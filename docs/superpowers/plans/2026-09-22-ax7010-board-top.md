# AX7010 Board Top and UART Bring-Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create an AX7010-only top-level that boots the internal RV32IM CPU from BRAM and sends `Hello RISC-V SoC\r\n` through UART.

**Architecture:** `board_top` is a narrow physical wrapper around `soc_top`: it fixes the internal-CPU configuration, uses a direct `defparam` to select a deterministic RAM image, ties simulation-only ports to constants, and maps reset readiness to LED0. A system-level test decodes the serial output and verifies reset/CPU behavior. The direct parameter override avoids Icarus Verilog 13.0's inability to forward a parent parameter into `onchip_ram`'s string parameter.

**Tech Stack:** SystemVerilog, Icarus Verilog 13.0 (`iverilog`/`vvp`), PowerShell test runner, AX7010 XDC.

**Files:**

- [ ] **Step 1: Register the new test and write the failing testbench**

Add this entry after `soc_top` in `$Tests`:

```powershell

```

Create `tb/top/tb_board_top.sv` with this test. It intentionally instantiates the not-yet-created `board_top`, so compilation must fail first.

```systemverilog
`timescale 1ns/1ps
module tb_board_top;
    localparam integer BAUD_DIV = 868;
    localparam integer MESSAGE_LEN = 18;
    logic clk_50m = 1'b0;
    logic rst_n = 1'b0;
    logic uart_rx = 1'b1;
    wire uart_tx;
    wire [0:0] led;
    logic [7:0] received [0:MESSAGE_LEN-1];
    integer i;

    board_top dut (
        .clk_50m(clk_50m), .rst_n(rst_n), .uart_rx(uart_rx),
        .uart_tx(uart_tx), .led(led)
    );

    always #10 clk_50m = ~clk_50m;

    task automatic check(input logic condition, input string message);
        if (!condition) $fatal(1, "%s", message);
    endtask

    task automatic receive_byte(output logic [7:0] value);
        integer bit_index;
        begin
            @(negedge uart_tx);
            repeat (BAUD_DIV + BAUD_DIV/2) @(posedge clk_50m);
            for (bit_index = 0; bit_index < 8; bit_index = bit_index + 1) begin
                value[bit_index] = uart_tx;
                repeat (BAUD_DIV) @(posedge clk_50m);
            end
            check(uart_tx === 1'b1, "UART stop bit was not high");
        end
    endtask

    initial begin
        repeat (250000) @(posedge clk_50m);
        $fatal(1, "Timed out waiting for complete UART hello message");
    end

    initial begin
        repeat (3) @(posedge clk_50m);
        check(led[0] === 1'b0, "LED asserted while reset was active");
        rst_n = 1'b1;
        repeat (5) @(posedge clk_50m);
        check(led[0] === 1'b1, "LED did not assert after reset synchronization");
        for (i = 0; i < MESSAGE_LEN; i = i + 1)
            receive_byte(received[i]);
        check({received[0], received[1], received[2], received[3], received[4],
               received[5], received[6], received[7], received[8], received[9],
               received[10], received[11], received[12], received[13], received[14],
               received[15], received[16], received[17]} ==
              "Hello RISC-V SoC\r\n", "UART hello message mismatch");
        check(!dut.u_soc.cpu_halted, "Internal CPU halted while transmitting hello");
        $display("PASS tb_board_top");
        $finish;
    end
endmodule
```

```systemverilog
module board_top (
    input  wire       clk_50m,
    input  wire       rst_n,
    input  wire       uart_rx,
    output wire       uart_tx,
    output wire [0:0] led
);
    wire phase1_ready;

    soc_top #(
        .INTERNAL_CPU(1'b1),
        .RAM_INIT_FILE("firmware/hello_uart.hex")
    ) u_soc (
        .clk_50m(clk_50m), .rst_n(rst_n), .uart_rx(uart_rx), .gpio_in(8'd0),
        .uart_tx(uart_tx), .gpio_out(), .gpio_dir(), .timer_irq(),
        .phase1_ready(phase1_ready),
        .cpu_req_valid(1'b0), .cpu_req_write(1'b0), .cpu_req_addr(32'd0),
        .cpu_req_wdata(32'd0), .cpu_req_wstrb(4'd0), .cpu_resp_rdata(),
        .cpu_resp_ready(), .cpu_resp_error(), .cpu_halted(), .cpu_fault_code(),
        .audio_clk(1'b0), .audio_rst_n(1'b0), .i2s_bclk(1'b0),
        .i2s_lrclk(1'b0), .i2s_sdata_in(1'b0), .i2s_sdata_out()
    );

    assign led[0] = phase1_ready;
endmodule
```

# AX7010 Board-Top UART Bring-Up

## Configuration

- Implementation top: `board_top`.
- Device and board constraints: AX7010, 50 MHz PL clock, J19/K19 UART, M14 LED.
- Internal CPU: enabled.
- BRAM image: `firmware/hello_uart.hex`.
- UART message: `Hello RISC-V SoC\r\n` at the UART default divisor of 868.

## Simulation command

```powershell
powershell -ExecutionPolicy Bypass -File sim/run_tests.ps1 -Test board_top
```

## Acceptance evidence

The test must report `PASS tb_board_top`, prove LED0 stays low in reset and becomes high after synchronized release, decode the complete 18-byte message, and verify the CPU did not halt.

## Boundary

This validates RTL simulation and a board-constrained top-level only. It does not claim Vivado implementation, timing closure, bitstream download, or real hardware UART capture.
```
