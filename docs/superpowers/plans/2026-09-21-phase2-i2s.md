# Phase Two I2S Audio Interface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reusable 16-bit stereo I2S slave RX/TX path for the AX7010 external expansion header and connect it to the existing audio processing path without changing the validated DMA path.

**Architecture:** External Codec supplies `i2s_bclk` and `i2s_lrclk`. `i2s_rx_slave` and `i2s_tx_slave` perform serial conversion in the BCLK domain. `i2s_audio_bridge` uses the existing `async_fifo` primitive to move ordered L/R 16-bit samples into and out of the existing `audio_pipeline` clock domain. `soc_top` exposes optional I2S pins and defaults to the existing DMA path.

**Tech Stack:** SystemVerilog RTL, Icarus Verilog (`iverilog`/`vvp`), existing `async_fifo`, existing `audio_pipeline`, PowerShell test runner.

## Global Constraints

- AX7010 target: XC7Z010-1CLG400I.
- Codec is external and provides BCLK/LRCLK; FPGA is an I2S slave.
- Samples are 16-bit stereo, MSB first, left channel before right channel.
- Standard I2S one-bit offset is required after each LRCLK transition.
- Existing DMA/BRAM audio path and all current tests must remain unchanged.
- No Codec-specific I2C initialization, PDM, master mode, or fixed board pin numbers in this phase.
- Every production change has a failing test before implementation.

### Task 1: I2S RX slave

**Files:**
- Create: `rtl/audio/i2s_rx_slave.sv`
- Create: `tb/audio/tb_i2s_rx_slave.sv`
- Modify: `sim/run_tests.ps1`

**Interfaces:**
- Inputs: `i2s_bclk`, `i2s_lrclk`, `i2s_sdata`, `rst_n`.
- Outputs: `sample_valid`, signed `sample_data[15:0]`, `sample_channel` (`0` left/`1` right), sticky `frame_error`.
- The module samples SDATA on BCLK rising edges. On LRCLK change it consumes one dummy bit, then shifts exactly 16 data bits; bit 15 is received first.

- [ ] **Step 1: Write the failing test**

Create a testbench that drives LRCLK and SDATA with two stereo frames (`16'h1234`, `16'hFEDC`) using one dummy BCLK edge after each LRCLK transition. Assert that four valid events arrive in L/R/L/R order and that no frame error is raised.

- [ ] **Step 2: Run the test and verify RED**

Run `pwsh -File sim/run_tests.ps1 -Test i2s_rx_slave`. Expected result: compile failure because `tb/audio/tb_i2s_rx_slave.sv` and the DUT do not yet exist.

- [ ] **Step 3: Implement the minimal RX state machine**

Implement a 16-bit shift register, a 5-bit bit counter, a one-cycle `skip_bit` flag after LRCLK changes, and a latched channel bit. Reset the shift state on LRCLK changes and assert `sample_valid` only when bit count reaches 16. Set `frame_error` if LRCLK changes while a partial sample is active.

- [ ] **Step 4: Run the test and verify GREEN**

Run `pwsh -File sim/run_tests.ps1 -Test i2s_rx_slave`. Expected output includes `PASS tb_i2s_rx_slave`.

- [ ] **Step 5: Commit**

Run `git add rtl/audio/i2s_rx_slave.sv tb/audio/tb_i2s_rx_slave.sv sim/run_tests.ps1; git commit -m "feat: add i2s slave receiver"`.

### Task 2: I2S TX slave

**Files:**
- Create: `rtl/audio/i2s_tx_slave.sv`
- Create: `tb/audio/tb_i2s_tx_slave.sv`
- Modify: `sim/run_tests.ps1`

**Interfaces:**
- Inputs: `i2s_bclk`, `i2s_lrclk`, `rst_n`, `sample_valid`, signed `sample_data[15:0]`.
- Outputs: `sample_ready`, `i2s_sdata`, sticky `underrun`.
- The module accepts samples in L/R order, updates SDATA on BCLK falling edges, inserts one zero-data offset bit after LRCLK transitions, and outputs zero samples when no sample is available.

- [ ] **Step 1: Write the failing test**

Drive two samples (`16'h1357`, `16'h2468`) into the TX handshake and sample SDATA on BCLK rising edges. Check the one-bit offset, MSB-first ordering, L/R ordering, and zero output when the source is empty.

- [ ] **Step 2: Run the test and verify RED**

Run `pwsh -File sim/run_tests.ps1 -Test i2s_tx_slave`. Expected result: compile failure because the DUT and test are new.

- [ ] **Step 3: Implement the minimal TX state machine**

Use separate left/right holding registers, a 5-bit shift counter, a channel selector derived from LRCLK, and a `valid_slot` flag. Load a held sample at the first data slot after the offset bit, drive bit 15 first, and set `underrun` when a slot has no held sample.

- [ ] **Step 4: Run the test and verify GREEN**

Run `pwsh -File sim/run_tests.ps1 -Test i2s_tx_slave`. Expected output includes `PASS tb_i2s_tx_slave`.

- [ ] **Step 5: Commit**

Run `git add rtl/audio/i2s_tx_slave.sv tb/audio/tb_i2s_tx_slave.sv sim/run_tests.ps1; git commit -m "feat: add i2s slave transmitter"`.

### Task 3: I2S/audio-pipeline bridge

**Files:**
- Create: `rtl/audio/i2s_audio_bridge.sv`
- Create: `tb/audio/tb_i2s_audio_bridge.sv`
- Modify: `sim/run_tests.ps1`

**Interfaces:**
- Clock/reset: `i2s_bclk`, `i2s_rst_n`, `audio_clk`, `audio_rst_n`.
- I2S pins: `i2s_lrclk`, `i2s_sdata_in`, `i2s_sdata_out`.
- Processing stream: `audio_in_valid`, signed `audio_in_data[15:0]`, `audio_in_ready`; signed `audio_out_data[15:0]`, `audio_out_valid`, `audio_out_ready`.
- Status: `rx_overflow`, `rx_frame_error`, `tx_underflow`.
- RX samples are enqueued in L/R order; TX consumes the same order. FIFO depth is parameterized and uses `async_fifo` for both directions.

- [ ] **Step 1: Write the failing test**

Instantiate the bridge with unrelated clocks, send one stereo frame into SDATA, consume the two output samples after a pass-through processing stream, and assert L/R order plus zero/error behavior during TX starvation.

- [ ] **Step 2: Run the test and verify RED**

Run `pwsh -File sim/run_tests.ps1 -Test i2s_audio_bridge`. Expected result: compile failure because the bridge and test are new.

- [ ] **Step 3: Implement bridge FIFOs and handshakes**

Connect `i2s_rx_slave` to an input async FIFO clocked by BCLK, expose FIFO reads as `audio_in_valid/data`, connect `audio_out_valid/data` to an output async FIFO clocked by `audio_clk`, and connect FIFO reads to `i2s_tx_slave`. Preserve sticky status outputs and never cross multi-bit samples without a FIFO.

- [ ] **Step 4: Run the test and verify GREEN**

Run `pwsh -File sim/run_tests.ps1 -Test i2s_audio_bridge`. Expected output includes `PASS tb_i2s_audio_bridge`.

- [ ] **Step 5: Commit**

Run `git add rtl/audio/i2s_audio_bridge.sv tb/audio/tb_i2s_audio_bridge.sv sim/run_tests.ps1; git commit -m "feat: bridge i2s samples across audio clock domains"`.

### Task 4: AX7010 top-level I2S ports

**Files:**
- Modify: `rtl/top/soc_top.sv`
- Create: `tb/top/tb_soc_i2s.sv`
- Modify: `sim/run_tests.ps1`

**Interfaces:**
- Add top-level ports `i2s_bclk`, `i2s_lrclk`, `i2s_sdata_in`, `i2s_sdata_out`.
- Add parameter `I2S_ENABLE` defaulting to `1'b0`.
- When disabled, preserve the current DMA/BRAM audio path exactly. When enabled, connect `i2s_audio_bridge` to the existing audio processing interface and leave DMA registers unchanged.

- [ ] **Step 1: Write the failing integration test**

Extend a top-level testbench with I2S clocks and pins, enable `I2S_ENABLE`, drive a known stereo frame, configure the existing audio control registers for bypass, and assert that TX returns the same two samples in L/R order. Compile should fail before the new ports/parameter exist.

- [ ] **Step 2: Run the test and verify RED**

Run `pwsh -File sim/run_tests.ps1 -Test soc_i2s`. Expected result: compile failure because `tb_soc_i2s.sv` and top-level I2S ports are new.

- [ ] **Step 3: Implement top-level integration**

Add the ports and parameter, route the bridge to the existing `audio_pipeline` stream, and use the parameter to select the I2S stream only in the new test configuration. Tie unused I2S inputs/outputs safely when disabled so existing instantiations continue to compile.

- [ ] **Step 4: Run the integration test and the existing audio tests**

Run `pwsh -File sim/run_tests.ps1 -Test soc_i2s`, then `pwsh -File sim/run_tests.ps1 -Test soc_audio`. Expected result: both pass.

- [ ] **Step 5: Commit**

Run `git add rtl/top/soc_top.sv tb/top/tb_soc_i2s.sv sim/run_tests.ps1; git commit -m "feat: expose i2s audio ports on soc top"`.
