# Phase 6 FIR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement and verify a standalone 16-tap signed Q1.15 FIR filter with streaming handshakes and saturating output.

**Architecture:** `fir_filter` stores programmable coefficients and a 16-sample history. Each accepted sample performs a complete signed multiply-accumulate, rounds and shifts the result, saturates to 16 bits, and holds the output until consumed.

**Tech Stack:** SystemVerilog 2012, Icarus Verilog 13.0, VVP, PowerShell.

## Global Constraints

- Default configuration is 16 taps, 16-bit samples, 16-bit coefficients, and a 40-bit accumulator.
- Samples and coefficients use signed Q1.15 representation.
- Tap zero is the newest sample; tap 15 is the oldest retained sample.
- Output uses nearest rounding at bit 14, arithmetic shift by 15, and signed 16-bit saturation.
- Input/output valid-ready signals must hold data stable under backpressure.
- Existing Phase 1 through Phase 5 tests must remain passing.
